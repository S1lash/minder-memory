## Notes

- Tags listed here are sourced from `tags:` lists in note frontmatter, knowledge layer only (excludes `_records/`, `_sources/`, `_system/`, `0_constitution/`, `6_posts/`) — plus two mechanical exclusions: `*.template.md` engine seeds and symlinks
- A tag repeated inside one note's `tags:` list counts once — a use is a note, not a mention
- Sections are namespaces, ordered by total uses; bare labels with no slash render last. Inside a section, tags are ordered by uses
- Convention drift: some tags use `cat/sub` and some use `cat-sub` — both are tolerated and counted as-is; the census surfaces the drift rather than merging it
- New tags should follow the dominant pattern in their category (look at existing usage)
